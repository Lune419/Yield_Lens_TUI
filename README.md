# Yield Lens：荷重／應力–應變 TUI

Python 3.10 以上。繁體中文、方向鍵操作的終端面板，以選單與曲線游標完成分析。可讀 `.xls`（包含附件的 BIFF2）、`.xlsx`、`.csv`、`.tsv`。資料只在本機處理。

## Windows 啟動

1. 安裝 Python 3.10 以上（建議 3.11/3.12，包含 Python Launcher）。
2. 解壓縮整個資料夾，雙擊 `start_windows.bat`。第一次會建立 `.venv` 並從網路安裝三個相依套件。
3. 沒有指定檔案時先找程式資料夾中的 Excel/CSV，找不到就開啟 `example/1 w.xls`。
4. 可把檔案或放有多份資料的資料夾拖到 `start_windows.bat` 上。建議使用 Windows Terminal、字型選 Consolas 或 Cascadia Mono，視窗約 110 欄 × 42 列。

自行啟動／macOS／Linux：

```sh
python -m pip install -r requirements.txt
python yield_tui.py "1 w.xls"
python yield_tui.py "data_folder"
python yield_tui.py "sample_a.xls" "sample_b.xls" --output results
```

若 Unicode 圖形顯示不正常，先更換終端字型。方向鍵介面使用單色高對比文字，傳統指令模式可用 `--no-color` 關閉圖表顏色。

## 方向鍵操作（預設）

雙擊 `start_windows.bat` 即進入選單，不必記指令，也不需安裝額外套件。

| 畫面 | 操作 |
|---|---|
| 選單 | ↑↓ 選擇，Enter 或 → 開啟，← 或 Esc 返回 |
| 曲線選點 | ↑↓ 移動 1 筆、←→ 移動 10 筆，Enter 選取，Esc 取消；Home/End 跳到首末筆 |
| 數值欄位 | ↑↓ 增減，←→ 調整步長，Enter 確認，Esc 取消；也可直接輸入數字 |
| 圖表與說明 | ↑↓ 捲動，Enter 或 ← 返回 |

建議流程：**單位設定 → 線性擬合 → 圖表／資料 → 匯出**。檔案、工作表、X/Y 欄位、方向、歸零、分析區間、偏離門檻、手動降伏點與縮放都有對應選單。

選取區間時分別確認起列和末列，曲線上的 `Y` 暫時表示目前游標；兩端確認後才套用。10–30% 建議區間可先預覽並調整，請確認它確實位於線性區。取消第二端時不會修改原本設定。

離開選單可選「匯出並離開」。分析設定目前只保留在本次工作階段，下次啟動不會自動還原。匯出結果包含已載入檔案的 JSON、CSV、SVG 與全檔摘要。

下方的文字指令仍可在傳統模式使用：`python yield_tui.py --commands`。非互動輸入也會自動使用傳統模式。

## 附件已確認的內容

`1 w.xls` 第一列只有 X/Y，沒有單位；有 2,303 筆數值，原始 Excel 第 2–2304 列。X 範圍約 −12.5605～0，Y 約 −7080.03～−1.83706。不能從這些數字確定 X 是 mm、百分比或應變，也不能確定 Y 是 N、kgf 或 MPa。

程式初次載入以首末點方向建議 `sign -1 -1`，**不使用絕對值**；面板會顯示此設定，可手動修改。原始資料不改寫。預設分析終點為方向修正後的第一個 Y 最大值；此附件為第 2266 列。畫面仍畫出完整曲線。

## 第一次操作順序

1. `help` 顯示全部指令。`files` 列出檔案，`use 2` 切到第 2 份；每份檔案保留各自的本次分析設定。
2. **確認單位**再設定 X/Y。不能把 0.2% 當成「X 最大值的 0.2%」。
3. `suggest` 提示由加載起點到峰值增量的 10–30% 對應列號；只是選區起點，不保證彈性區，必須檢查曲線並自行用 `fit 起列 末列` 套用。
4. 查看擬合線、R²、RMSE。改動擬合區間，確認交點對區間是否敏感。高 R² 本身不代表選中的一定是彈性區。
5. `view 左界 右界` 放大轉換後 X 範圍；`view all` 恢復。`rows 400 410` 查原始列與數值。
6. O 標記 offset 交點，C 是偏離線性的候選點。依課程定義及曲線判讀後，以 `yield 原始列號` 手動標記真正要報告的降伏點 Y。
7. `export` 匯出已載入檔案的結果和全檔案狀態總表，再 `q` 離開。**此版不會自動恢復上次會話**；JSON 保留設定供稽核與手動重設。

## 單位指令

| 你確認的原始 X 意義 | 指令 | 程式使用的應變 |
|---|---|---|
| mm/mm，無因次 | `x strain` | X |
| 百分比，例如 1 代表 1% | `x percent` | X/100 |
| 微應變 με | `x micro` | X×10⁻⁶ |
| 拉伸標距伸長 mm，原始標距 50 mm | `x tensile 50` | X/50 |
| 已由課程公式推得係數 k | `x custom k` | X×k |
| 尚未確認 | `x unknown` | 只畫原始 X，不計算 offset |

上表運算前會套用方向與選填的歸零。`x tensile` **只適用於標距伸長**；彎曲試驗的壓頭位移不可直接除以試片長度冒充應變，機台橫樑位移也可能包含機架／夾具變形。本程式沒有擅自套用矩形截面公式到梯形試片。若是彎曲試驗，先確認老師的位移→表面應變公式；固定幾何且為線性換算時，可將係數填入 `x custom`。

`y N`、`y kN`、`y kgf`、`y MPa` 是宣告原資料單位，不改變大小。`y custom k MPa` 才會乘 k，適用於已由課程荷重→應力公式計算出固定係數的情況。原資料已是 MPa 時用 `y MPa`，不要再乘彎曲應力換算係數。僅有荷重時，offset 結果就是荷重，不能稱為應力。

## 常用指令

| 指令 | 功能 |
|---|---|
| `sign -1 -1` | 兩軸反向，保留真正的符號變化 |
| `sheet 2` | 第 2 張工作表；重新初始化設定 |
| `cols 1 2` | 第一欄 X、第二欄 Y；重新初始化設定 |
| `zero 2` / `zero off` | 選擇／取消扣除第 2 列 X/Y 基準 |
| `branch 2 2266` / `branch auto` | 選單次加載區間／恢復自動終點 |
| `fit 350 450` / `fit off` | 指定／取消線性回歸區間（範例列號，非建議答案） |
| `yield 520` / `yield off` | 手動標記／取消降伏點 |
| `tol 0.02 5` | 候選點門檻參數及連續筆數 |
| `view 0.01 0.05` | 應變確認後，放大 0.01–0.05 mm/mm |
| `export` | 新建時間戳記資料夾，不覆盖前次輸出 |

所有列號都對應原始 Excel／CSV 的實際列，**包含標題列**。列不是時間，也不是應變值。非有限值、空白、文字列略過並計數；不排序、不平滑、不刪離群點、不自動改原始量測。可用 `branch` 切出單次加載；offset 搜尋遇到 X 回退便停止，避免跨過卸載或另一個循環。微小回退也會停止，需自行確認資料或區間，程式不會偷偷修正。

## 計算方式

在選取的線性區間，最小平方法擬合：

```
Y = k ε + b
offset line: Y = k (ε − 0.002) + b
```

應變統一成無因次 mm/mm，所以 0.2% = 0.002。保留截距 b，不强迫通過原點；offset 線由擬合線沿應變方向平移 0.002。若 Y 是荷重，k 只是荷重／應變斜率，並不是楊氏模數。

從擬合區間末點往後搜尋首次「曲線由 offset 線上方穿到下方」的相鄰點。令：

```
d_i = Y_i − [k(ε_i − 0.002) + b]
t = d_i / (d_i − d_(i+1))
ε* = ε_i + t(ε_(i+1) − ε_i)
Y* = Y_i + t(Y_(i+1) − Y_i)
```

僅在線性區間之後、選定加載範圍內搜尋；沒有交點就顯示未取得，不外插、不取最近點。JSON 保存交點兩側原始列號與內插比例。

**C 候選點不是 Yield point 的標準定義。** 它是擬合區間之後，連續 n 筆滿足 `kε+b−Y > 門檻` 的第一筆。預設門檻為 `max(0.02×擬合区間Y全距, 3×擬合RMSE)`，n=5。它只協助定位曲線偏離直線的位置，對選區、雜訊與採樣密度敏感，不等於已證明塑性開始、上降伏點或下降伏點。此版不自動辨識上／下降伏點；手動標記也保留「使用者指定，非程式驗證」註記。沒有明顯降伏現象的曲線，不應強行挑一個轉折當降伏點。

## 輸出與限制

- 每份已載入資料：JSON（原檔 SHA-256、單位／方向／歸零／選區設定、回歸、交點、候選點、手動點、警告）、CSV（原始值、轉換值、兩條擬合線）、SVG（全曲線與標記，可用瀏覽器開啟或插入簡報）。
- `summary.csv`：所有輸入檔案的分析狀態與結果；尚未開啟的檔案列為未分析，**不會用一份設定偷偷批次套用**。
- 每個輸入檔案目前只維持一張工作表的分析狀態。切換工作表或欄位會重新初始化；需要保存前一張結果時先 export。
- 匯出圖是全範圍圖，TUI 的局部放大設定不影響匯出。
- 這是判讀工具，不宣稱符合 ASTM/ISO 試驗標準；需要正確的量測種類、試片幾何與課程公式才能解讀為材料應力／應變。
- 未驗證 Windows 真機雙擊行為；已在 Linux 執行數值測試、原始 BIFF2 讀取與 TUI 指令流程測試。
